  │ GET    │ /api/v1/resumes/{id}                │ ALL              │ Lấy chi tiết resume           │

  ├────────┼─────────────────────────────────────┼──────────────────┼───────────────────────────────┤
  │ PATCH  │ /api/v1/resumes/{id}/status         │ RECRUITER, ADMIN │ Cập nhật status               │
