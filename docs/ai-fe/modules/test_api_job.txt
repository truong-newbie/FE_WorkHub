  8. GET /api/v1/jobs/search - Tìm kiếm Jobs

  Roles: ALL

  Query Parameters:

  ┌────────────┬─────────────────────────────────────────────────────────┐
  │   Param    │                       Description                       │
  ├────────────┼─────────────────────────────────────────────────────────┤
  │ page       │ Trang hiện tại                                          │
  ├────────────┼─────────────────────────────────────────────────────────┤
  │ size       │ Số items/trang                                          │
  ├────────────┼─────────────────────────────────────────────────────────┤
  │ sortBy     │ Trường sắp xếp                                          │
  ├────────────┼─────────────────────────────────────────────────────────┤
  │ direction  │ ASC/DESC                                                │
  ├────────────┼─────────────────────────────────────────────────────────┤
  │ keyword    │ Tìm kiếm theo name/description                          │
  ├────────────┼─────────────────────────────────────────────────────────┤
  │ skill      │ ID của skill (single)                                   │
  ├────────────┼─────────────────────────────────────────────────────────┤
  │ skills     │ IDs của skills (comma-separated, multiple)              │
  ├────────────┼─────────────────────────────────────────────────────────┤
  │ salaryFrom │ Lương tối thiểu                                         │
  ├────────────┼─────────────────────────────────────────────────────────┤
  │ salaryTo   │ Lương tối đa                                            │
  ├────────────┼─────────────────────────────────────────────────────────┤
  │ location   │ Địa điểm (contains)                                     │
  ├────────────┼─────────────────────────────────────────────────────────┤
  │ level      │ Level (INTERN, FRESHER, JUNIOR, MIDDLE, SENIOR, LEADER) │
  └────────────┴─────────────────────────────────────────────────────────┘

  Examples:
  GET /api/v1/jobs/search?keyword=java
  GET /api/v1/jobs/search?skill=1
  GET /api/v1/jobs/search?skills=1,2,3
  GET /api/v1/jobs/search?salaryFrom=1000&salaryTo=3000
  GET /api/v1/jobs/search?location=Ha Noi&level=SENIOR
  GET /api/v1/jobs/search?keyword=backend&skills=1,5&salaryFrom=2000

  Response (200 OK): Giống endpoint 7

  11. GET /api/v1/jobs/{jobId}/resumes - Resumes của Job

  Roles: ADMIN, RECRUITER (chỉ job của công ty mình)

  Example: GET /api/v1/jobs/1/resumes?page=1&size=10

  Response (200 OK): Danh sách resumes apply vào job đó

  ---
  Level Enum Values

  "INTERN", "FRESHER", "JUNIOR", "MIDDLE", "SENIOR", "LEADER"

  Status Enum Values

  "OPEN"   - Job đang tuyển dụng (endDate > now, deleted = false)
  "CLOSED" - Job đã đóng (endDate <= now)
  "DELETED" - Job đã xóa mềm (deleted = true)

  Error Responses

  404 Not Found:
  {
      "success": false,
      "data": {
          "code": 7001,
          "message": "Job not found",
          "path": "/api/v1/jobs/999"
      },
      "code": 404,
      "path": "/api/v1/jobs/999"
  }

  403 Access Denied:
  {
      "success": false,
      "data": {
          "code": 7004,
          "message": "Access denied to this job",
          "path": "/api/v1/jobs/5"
      },
      "code": 403,
      "path": "/api/v1/jobs/5"
  }

  400 Bad Request (Closed Job):
  {
