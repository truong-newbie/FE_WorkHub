  9. LIST Users (Admin only)

  GET /api/v1/users?page=1&size=10&sortBy=createdAt&direction=DESC&keyword=john
  Authorization: Bearer <token>

  Query Parameters:

  ┌───────────┬───────────┬────────────────────────┐
  │   Param   │  Default  │      Description       │
  ├───────────┼───────────┼────────────────────────┤
  │ page      │ 1         │ Page number            │
  ├───────────┼───────────┼────────────────────────┤
  │ size      │ 10        │ Items per page         │
  ├───────────┼───────────┼────────────────────────┤
  │ sortBy    │ createdAt │ Sort field             │
  ├───────────┼───────────┼────────────────────────┤
  │ direction │ DESC      │ ASC/DESC               │
  ├───────────┼───────────┼────────────────────────┤
  │ keyword   │ null      │ Search username, email │
  ├───────────┼───────────┼────────────────────────┤
  │ filter    │ null      │ Advanced filter        │
  └───────────┴───────────┴────────────────────────┘

  10. FILTER Examples

  GET /api/v1/users?filter=role:ROLE_ADMIN
  GET /api/v1/users?filter=enabled=true,username:*john*
  GET /api/v1/users?filter=(role:ROLE_ADMIN|role:ROLE_RECRUITER),enabled=true
