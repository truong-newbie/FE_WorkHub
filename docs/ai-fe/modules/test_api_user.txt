User API Documentation
Module: User Management

Base URL: /api/v1/users
Authentication: Bearer Token (JWT)
Content-Type: application/json

4. Delete User
Soft delete user (Admin only)
Endpoint
DELETE /api/v1/users/{id}
Authorization
Required
Role: ROLE_ADMIN
Path Variables
Variable	Type	Description
id	Long	User ID
Business Rules
Cannot delete current logged-in admin
Cannot delete the last remaining admin
Soft delete only (deleted = true)
5. Lock User
Lock user account (Admin only)
Endpoint
PATCH /api/v1/users/{id}/lock
Authorization
Required
Role: ROLE_ADMIN
Business Rules
Locked user cannot login
accountNonLocked = false
6. Unlock User
Unlock user account (Admin only)
Endpoint
PATCH /api/v1/users/{id}/unlock
Authorization
Required
Role: ROLE_ADMIN
Business Rules
accountNonLocked = true
7. Disable User
Disable user account (Admin only)
Endpoint
PATCH /api/v1/users/{id}/disable
Authorization
Required
Role: ROLE_ADMIN
Business Rules
Disabled user cannot access system
enabled = false
8. Enable User
Enable user account (Admin only)
Endpoint
PATCH /api/v1/users/{id}/enable
Authorization
Required
Role: ROLE_ADMIN
Business Rules
enabled = true
9. List Users
Get paginated user list (Admin only)
Endpoint
GET /api/v1/users
Example Request
GET /api/v1/users?page=1&size=10&sortBy=createdAt&direction=DESC&keyword=john
Authorization
Required
Role: ROLE_ADMIN
Query Parameters
Parameter	Default	Description
page	1	Current page number
size	10	Number of items per page
sortBy	createdAt	Sort field
direction	DESC	Sort direction (ASC or DESC)
keyword	null	Search by username or email
filter	null	Advanced filtering
Supported Search

Keyword search supports:

Username
Email

10. Advanced Filter
Filter Syntax
field:value
Multiple Conditions
field1:value1,field2:value2
OR Condition
(field1:value1|field2:value2)
Wildcard Search
username:*john*
Filter Examples
Filter by role
GET /api/v1/users?filter=role:ROLE_ADMIN
Filter enabled users with username contains "john"
GET /api/v1/users?filter=enabled=true,username:*john*
Filter admin or recruiter and enabled users
GET /api/v1/users?filter=(role:ROLE_ADMIN|role:ROLE_RECRUITER),enabled=true
User Entity Overview
Field	Description
enabled	User activation status
accountNonLocked	Account lock status
deleted	Soft delete status
role	System role
companyId	Associated company
createdBy	User who created record
updatedBy	Last user who updated record
Roles
Role	Description
ROLE_ADMIN	System administrator
ROLE_RECRUITER	Recruiter user
ROLE_CANDIDATE	Candidate user
Common HTTP Status Codes
Status	Meaning
200	Success
201	Created successfully
400	Validation error
401	Unauthorized
403	Forbidden
404	User not found
409	Conflict
500	Internal server error
