3. Create Job Preference
POST /api/v1/candidate/job-preference
Auth: ROLE_CANDIDATE.
Request body:
{
  "desiredJobTitle": "Java Backend Developer",
  "preferredLocation": "Ha Noi",
  "workMode": "HYBRID",
  "employmentType": "FULL_TIME",
  "candidateLevel": "JUNIOR",
  "experienceYears": 1,
  "expectedSalaryMin": 800,
  "expectedSalaryMax": 1500,
  "skillIds": [1, 2, 3]
}
Enum hợp lệ:
workMode: ONSITE | REMOTE | HYBRID
employmentType: FULL_TIME | PART_TIME | INTERNSHIP | FREELANCE | CONTRACT
candidateLevel: STUDENT | INTERN | FRESHER | JUNIOR | MIDDLE | SENIOR

6. Recommended Jobs

Rule chính của recommend:
Chỉ lấy job chưa hết hạn, chưa deleted.
Không recommend job candidate đã apply.
Sort theo matchScore DESC, nếu bằng nhau sort createdDate DESC.
Candidate phải có job preference trước.
Error response mẫu:
{
  "code": 9003,
  "message": "Candidate job preference is required",
  "path": "api/v1/candidate/jobs/recommended",
  "timestamp": 1779177600000
}
Một số error code liên quan:
9001: Candidate job preference already exists
9002: Candidate job preference not found
9003: Candidate job preference is required
9004: Expected salary max must be greater than or equal to salary min
9005: One or more skills were not found
9006: Only candidates can use this feature
1002: Invalid input
