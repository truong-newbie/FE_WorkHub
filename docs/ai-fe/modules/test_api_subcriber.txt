  Email Scheduler

  Cron Expression: 0 */30 * * * ? (chạy mỗi 30 phút)

  Flow:
  1. Scheduler trigger mỗi 30 phút
  2. Lấy tất cả subscribers đang active và enabled
  3. Với mỗi subscriber, tìm jobs matching với skills của họ
  4. Gửi email với danh sách jobs (tối đa 10 jobs)
  5. Update lastSentAt và emailSentCount

  Email Format:
  Subject: New Jobs Matching Your Skills

  Hello Truong,

  We found new jobs matching your skills:

  1. Senior Java Developer
     Company: FPT Software
     Location: Ha Noi
     Salary: $2000
     Level: SENIOR
     Apply: https://workhub.example.com/jobs/1

  2. Spring Boot Engineer
     Company: Viettel
     Location: Ho Chi Minh
     Salary: $1500
     Level: MIDDLE
     Apply: https://workhub.example.com/jobs/5

  ---
  Best regards,
  WorkHub Team

  To manage your subscription, visit: https://workhub.example.com/subscribers
  To unsubscribe, reply with 'UNSUBSCRIBE' in the subject.

  Cách test

  1. Chuẩn bị dữ liệu test

  Tạo Subscriber (đăng ký nhận email):
  POST /api/v1/subscribers
  {                                                                                                                           "name": "Test User",
      "email": "test@example.com",                                                                                            "skillIds": [1, 2, 3]
  }

  Tạo Job với skills matching:
  POST /api/v1/jobs
  {
      "name": "Senior Java Developer",
      "location": "Ha Noi",
      "salary": 2000,
      "quantity": 5,
      "level": "SENIOR",
      "description": "Java Spring Boot",
      "startDate": "2026-05-01T00:00:00Z",
      "endDate": "2026-06-01T00:00:00Z",
      "companyId": 1,
      "skillIds": [1, 2]
  }

  2. Test bằng Postman

  Trigger email thủ công (ADMIN only):
  POST http://localhost:8080/api/v1/test/trigger-job-matching-email
  Authorization: Bearer <admin_jwt_token>

  Test xem jobs match như thế nào (ADMIN only):
  POST http://localhost:8080/api/v1/test/test-matching-jobs
  Authorization: Bearer <admin_jwt_token>

  3. Cron tự động

  Cron chạy mỗi 30 phút với expression: 0 */30 * * * ?

  Để thay đổi schedule, sửa trong JobMatchingScheduler.java:

  // Mỗi 30 phút (mặc định)
  @Scheduled(cron = "0 */30 * * * ?")

  // Mỗi 1 giờ
  @Scheduled(cron = "0 0 * * * ?")

  // Mỗi ngày lúc 9h sáng
  @Scheduled(cron = "0 0 9 * * ?")

  // Mỗi ngày lúc 8h, 12h, 6h
  @Scheduled(cron = "0 0 8,12,18 * * ?")

  4. Check logs
