Candidate APIs
POST /api/v1/candidate/recruiter-requests
Role: ROLE_CANDIDATE
Request independent recruiter:
{
  "type": "INDEPENDENT_RECRUITER",
  "reason": "Toi muon tro thanh recruiter"
}
Request join company:
{
  "type": "JOIN_COMPANY",
  "companyId": 1,
  "reason": "Toi la HR cua cong ty nay"
}
Expected response 201:
{
  "success": true,
  "meta": {
    "code": 201,
    "path": "/api/v1/candidate/recruiter-requests"
  },
  "data": {
    "id": 1,
    "candidateId": 10,
    "candidateName": "candidate01",
    "candidateEmail": "candidate01@gmail.com",
    "companyId": 1,

    "type": "JOIN_COMPANY",
    "status": "PENDING",
    "reason": "Toi la HR cua cong ty nay",
    "adminNote": null,
    "reviewedById": null,
    "reviewedByName": null,
    "reviewedAt": null,
    "createdDate": "2026-05-19T21:00:00"

Role: ROLE_CANDIDATE

GET /api/v1/candidate/recruiter-requests/status
Role: ROLE_CANDIDATE
Expected response 200: trả về request mới nhất để frontend đọc status.

GET /api/v1/admin/recruiter-requests/{id}
Role: ROLE_ADMIN
Expected response 200: một RecruiterRequestResponse.
PUT /api/v1/admin/recruiter-requests/{id}/approve
Role: ROLE_ADMIN
Request body: không cần body.
Expected response 200:
{
  "success": true,
  "meta": {
    "code": 200,
    "path": "/api/v1/admin/recruiter-requests/1/approve"
  },
  "data": {
    "id": 1,
    "status": "APPROVED",
    "reviewedById": 1,
    "reviewedByName": "admin"
  },
  "error": null,
  "timestamp": "2026-05-19T21:00:00"
}
Logic mong đợi:
•
INDEPENDENT_RECRUITER: user đổi role thành ROLE_RECRUITER.
•
JOIN_COMPANY: user đổi role thành ROLE_RECRUITER, user.company = targetCompany.
PUT /api/v1/admin/recruiter-requests/{id}/reject
Role: ROLE_ADMIN
Request body:
{
  "adminNote": "Thong tin chua hop le"
}
Expected response 200: request có status = REJECTED, lưu adminNote, reviewedBy, reviewedAt.
Company Owner APIs
GET /api/v1/recruiter/company/recruiter-requests?page=1&size=10
Role: ROLE_RECRUITER
Rule: chỉ company owner được xem request join vào company mình.
Expected response 200: paginated list RecruiterRequestResponse.
PUT /api/v1/recruiter/recruiter-requests/{id}/approve
Role: ROLE_RECRUITER
Request body: không cần body.
Rule:
•
Chỉ approve request JOIN_COMPANY.
•
Current recruiter phải là targetCompany.owner.
Expected response 200: request APPROVED, candidate thành ROLE_RECRUITER và join company.
PUT /api/v1/recruiter/recruiter-requests/{id}/reject
Role: ROLE_RECRUITER
Request body:
{
  "adminNote": "Owner tu choi yeu cau join company"
}
Expected response 200: request REJECTED.

Job API
POST /api/v1/jobs
Role: ROLE_RECRUITER
Request body:
{
  "name": "Java Backend Engineer",
  "location": "Ho Chi Minh City",
  "salary": 2000,
  "quantity": 2,
  "level": "MIDDLE",
  "description": "Quarkus backend role",
  "startDate": "2026-05-19T00:00:00Z",
  "endDate": "2026-06-19T00:00:00Z",
  "skillIds": []
}
Expected response 201:
{
  "success": true,
  "meta": {
    "code": 201,
    "path": "/api/v1/jobs"
  },
  "data": {
    "id": 1,
    "name": "Java Backend Engineer",
    "companyId": 1,
    "companyName": "WorkHub Company",
    "recruiterId": 5,
    "recruiterName": "recruiter01",
    "status": "OPEN"
  },
  "error": null,
  "timestamp": "2026-05-19T21:00:00"
}
Rule:
•
Recruiter phải thuộc company.
•
Company phải APPROVED.
•
verified = true.
•
active = true.
•
System tự lấy company từ current recruiter, không tin theo companyId trong request.
Error Response Mong Đợi
Ví dụ khi đang có request PENDING:
{
  "code": 10002,
  "message": "A pending recruiter request already exists",
  "path": "api/v1/candidate/recruiter-requests"
}
Một số lỗi chính:
•
10002: đã có recruiter request pending.
•
10003: user đã là recruiter.
•
10004: JOIN_COMPANY thiếu companyId.
•
10005: INDEPENDENT_RECRUITER không được gửi companyId.
•
10006: request đã approve/reject rồi.
•
10007: company chưa approved/verified/active.
•
11001: recruiter đã thuộc company.
•
11002: recruiter đã own company.
•
12002: recruiter chưa thuộc company nên không tạo job được.
•
12003: company chưa approved/verified/active nên không tạo job được
