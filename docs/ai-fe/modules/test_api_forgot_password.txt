API Forgot Password - Test với Postman

  1. Step 1: Verify Email (Gửi OTP)

  POST http://localhost:8080/api/v1/forgot-password/verify-email
  Content-Type: application/json                                                                                                                                            
  Request Body:                                                                                                                                                               {
    "email": "user@example.com"
  }

  Response thành công (200 OK):
  {
    "success": true,
    "meta": { "code": 200, "path": "/api/v1/forgot-password/verify-email" },
    "data": {
      "message": "OTP sent to your email. Please check and enter the 6-digit code.",
      "email": "u***@example.com",
      "expiresInSeconds": 60
    },
    "timestamp": "2026-05-08T20:00:00"
  }

  Error - Email không tồn tại (400):
  {
    "code": 3006,
    "message": "Email not found in our system",
    "path": "/api/v1/forgot-password/verify-email"
  }

  Error - Rate Limit (400):
  {
    "code": 3004,
    "message": "Please wait before requesting another OTP",
    "path": "/api/v1/forgot-password/verify-email"
  }

  ---
  2. Step 2: Verify OTP (Xác thực OTP)

  POST http://localhost:8080/api/v1/forgot-password/verify-otp
  Content-Type: application/json

  Request Body:
  {
    "email": "user@example.com",
    "otp": "123456"
  }

  Response thành công (200 OK):
  {
    "success": true,
    "meta": { "code": 200, "path": "/api/v1/forgot-password/verify-otp" },
    "data": "OTP verified successfully. Please enter your new password.",
    "timestamp": "2026-05-08T20:00:00"
  }

  Error - OTP sai (400):
  {
    "code": 3002,
    "message": "Invalid OTP",
    "path": "/api/v1/forgot-password/verify-otp"
  }

  Error - OTP hết hạn (400):
  {
    "code": 3001,
    "message": "OTP has expired",
    "path": "/api/v1/forgot-password/verify-otp"
  }

  ---
  3. Step 3: Change Password (Đổi mật khẩu)

  POST http://localhost:8080/api/v1/forgot-password/change-password
  Content-Type: application/json

  Request Body:
  {
    "email": "user@example.com",
    "otp": "123456",
    "newPassword": "newPassword123",
    "repeatPassword": "newPassword123"
  }

  Response thành công (200 OK):
  {
    "success": true,
    "meta": { "code": 200, "path": "/api/v1/forgot-password/change-password" },
    "data": "Password changed successfully. You can now login with your new password.",
    "timestamp": "2026-05-08T20:00:00"
  }

  Error - Password không khớp (400):
  {
    "code": 3005,
    "message": "Passwords do not match",
    "path": "/api/v1/forgot-password/change-password"
  }

  ---
  Security Flow Explanation

  User Request OTP
        ↓
  Check email exists? ─NO→ Return generic "Email not found"
        ↓ YES
  Check rate limit? ─EXCEEDED→ Return "Please wait 60 seconds"
        ↓ OK
  Generate 6-digit OTP
        ↓
  Hash OTP with BCrypt
        ↓
  Save hashed OTP to DB with expiry (60 seconds)
        ↓
  Send plain OTP via email
        ↓
  Return masked email

  User enters OTP
        ↓
  Find user by email
        ↓
  Find valid OTP record
        ↓
  Compare plain OTP with hashed OTP (BCrypt.checkpw)
        ↓
  OTP matches & not expired? ─NO→ Return "Invalid OTP" or "OTP expired"
        ↓ YES
  Mark OTP as verified
        ↓
  Return success

  User enters new password
        ↓
  Check passwords match
        ↓
  Find verified OTP
        ↓
  BCrypt hash new password
        ↓
  Update user.password in DB
        ↓
  Mark OTP as used
        ↓
  Delete all OTPs for user
        ↓
  Return success
