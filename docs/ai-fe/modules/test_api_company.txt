  7. ADVANCED FILTER Examples

  Filter by name contains

  GET /api/v1/companies?filter=name:*fpt*

  Filter by multiple conditions (AND)

  GET /api/v1/companies?filter=name:*fpt*,address:*hanoi*

  Filter with OR group

  GET /api/v1/companies?filter=(name:*fpt*|name:*viettel*)

  Filter with comparison

  GET /api/v1/companies?filter=id>5

  Combined keyword + filter + pagination

  GET /api/v1/companies?keyword=software&filter=name:*tech*,address:*hanoi*&page=1&size=5&sortBy=createdAt&direction=DESC

  ---
  Query Parameters Summary

  ┌───────────┬────────┬───────────┬─────────────────────────────────────────────┐
  │ Parameter │  Type  │  Default  │                 Description                 │
  ├───────────┼────────┼───────────┼─────────────────────────────────────────────┤
  │ page      │ int    │ 1         │ Page number (1-based)                       │
  ├───────────┼────────┼───────────┼─────────────────────────────────────────────┤
  │ size      │ int    │ 10        │ Items per page (max 100)                    │
  ├───────────┼────────┼───────────┼─────────────────────────────────────────────┤
  │ sortBy    │ string │ createdAt │ Sort field (id, name, createdAt, updatedAt) │
  ├───────────┼────────┼───────────┼─────────────────────────────────────────────┤
  │ direction │ string │ DESC      │ Sort direction (ASC, DESC)                  │
  ├───────────┼────────┼───────────┼─────────────────────────────────────────────┤
  │ keyword   │ string │ null      │ Search in name, description, address        │
  ├───────────┼────────┼───────────┼─────────────────────────────────────────────┤
  │ filter    │ string │ null      │ Advanced filter expression                  │
  └───────────┴────────┴───────────┴─────────────────────────────────────────────┘
